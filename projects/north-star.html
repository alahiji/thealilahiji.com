North Star

Leadership task and project-management platform, migrated from a laptop Flask app to Azure.

RoleDesigner, developer, cloud migration owner
PeriodMay 2026 – Aug 2026
Stack
FlaskAzure Web AppAzure SQLPython
Data handlingHIPAA · Security-reviewed

Holds no patient data; still reviewed under the hospital's security standard before go-live.

Problem

Hospital leadership tracked strategic initiatives across email threads and slide decks; nothing showed owners, status and blockers in one place.

Approach

Built North Star as a Flask application, then re-platformed it to an Azure Web App backed by Azure SQL so it could be shared organisation-wide, handed the Azure resources to the company tenant, and walked the security team through access and data flows.

Architecture

Azure Web App (Python) → Azure SQL; Entra-based access; environment-per-stage deployment.

Flask app (local)→Azure Web App→Azure SQL→Entra access→Leadership views

By the numbers

Azure Web App + Azure SQLPlatform
Passed security handoffReview
Executive & director levelUsers

Outcome

Adopted by leadership as the tracking system for organisational priorities; passed internal security review on handoff.

What I would tell your team

Ask me how this maps onto your EHR, your interface engine and your security review. I can walk through the data flow, the failure modes we hit at go-live, and what I would do differently the second time.
