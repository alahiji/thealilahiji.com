Mission Control

Real-time patient-flow dashboard fed by the hospital's HL7 ADT stream.

RoleArchitect and developer
PeriodNov 2025 – Dec 2025
Stack
.NETTCP / MLLP listenerHL7 ADTSQL ServerWeb dashboard
Data handlingHIPAA · On-prem

Runs entirely inside the hospital network; identifiers are displayed only to authorised roles.

Problem

Operations and nursing leadership had no live view of admissions, transfers and discharges; census questions were answered by phone calls and stale reports.

Approach

Wrote a .NET service that listens for ADT messages over TCP/MLLP, parses A01/A02/A03/A08 events, and writes a normalised event stream. A web dashboard reads that stream and shows live census, bed movements and alerts.

Architecture

Listener service → parser → SQL Server event tables → dashboard with auto-refresh; designed so additional message types (ORU, ORM) can be added without touching the UI.

HL7 ADT over TCP/MLLP→.NET listener service→Parser · event tables→SQL Server→Live dashboard
