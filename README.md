## Deploy to GitHub Pages (5 minutes)
1. Create a **new public repo** named `alahiji.github.io` (or any name + custom domain).
   Do not publish this journal repo.
2. Copy the contents of this folder to the new repo root and push:
   ```bash
   git clone https://github.com/alahiji/alahiji.github.io && cd alahiji.github.io
   cp -r /path/to/ai-growth-journal/portfolio/site/. .
   git add -A && git commit -m "Portfolio site" && git push
   ```
3. In the new repo: Settings → Pages → Source: **GitHub Actions**. The included workflow deploys on every push to `main`.
4. Optional custom domain: add a `CNAME` file with your domain and point DNS at GitHub Pages; then change `SITE_URL` in `build_site.py`, rebuild, and re-copy.

Alternatives: drag the folder onto Netlify Drop, or `vercel deploy` from inside it.

## Before going live
- Replace `assets/headshot.jpg` with a real square photo.
- Replace `assets/Ali-Lahiji-CV.pdf` when the CV changes (`_summary/resume/2026-cv-designs/`).
- `https://github.com/alahiji` is linked in the footer/contact; make sure that profile has 2–3 public sanitized repos.
- Update `now.html` monthly (`site-content.json` → `now`, then rebuild).
